Stable Diffusion
================

This project offloads parts of Stable Diffusion-like models to run on NPU using :term:`DD`.
`Stable Diffusion <https://stability.ai/>`__ (SD) is a series of prompt to image generation models.

This page documents how to take a standard float32 SD model and transform it into a fused model for NPU.
