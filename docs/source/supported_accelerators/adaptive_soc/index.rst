Quark for AMD Adaptive SoCs
===========================

Quark is the quantization flow compatible with `Vitis AI Software <https://www.amd.com/en/products/software/vitis-ai.html>`_ when targeting `Versal AI Edge Series Gen 2 <https://www.amd.com/en/products/adaptive-socs-and-fpgas/versal/gen2/ai-edge-series.html>`_ devices. For more details about Versal AI Edge Series Gen 2 quantization capabilities, please visit `Model Quantization <https://vitisai.docs.amd.com/projects/gen2/en/latest/docs/model_quantization/model_quantization.html>`_.

.. note::

    Please use the Quark release packaged with Vitis AI as described the instructions in `Vitis AI Software Setup <https://vitisai.docs.amd.com/projects/gen2/en/latest/docs/setup_and_installation/software_setup.html>`_ to get started.
