AutoSearch
==========

AMD Quark provides two automatic search workflows for finding good
quantization configurations without manual tuning. Use the original
**AutoSearch** for the iterative refinement loop, or **AutoSearch Pro**
for the Optuna-based parallel hyperparameter search with hierarchical
conditional search spaces.
