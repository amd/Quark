Community ONNX Passes
=====================

Community-contributed ONNX passes operate on ONNX graph models
(``onnx.ModelProto``) and use the ``onnx_`` pass-name prefix, exactly like core
ONNX passes. For the implementation contract, naming conventions, and worked
examples, see :doc:`ONNX Model Passes </quark_shapeshifter_onnx_passes>` and
:doc:`Adding New Passes </quark_shapeshifter>`.

No community ONNX passes are currently shipped. When you contribute one, document
it here with its pass name, configuration parameters, and behavior, matching the
style of the core ONNX pass reference.
