# Quark `contrib` Tutorials

Jupyter tutorials for community-authored extensions in Quark's `contrib` area live
here, under `tutorials/contrib/<component-name>/`, alongside the core tutorials so
they are easy to discover. The component's package code, tests, and documentation
live under `quark/contrib/<component-name>/`; only its runnable tutorials live here.
Reference each tutorial from the component's `quark/contrib/<component-name>/docs/index.rst`
so it appears under the component's documentation. Visit
https://quark.docs.amd.com/latest/intro_contrib.html for more information.
